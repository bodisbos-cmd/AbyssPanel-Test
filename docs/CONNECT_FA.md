# راهنمای اتصال و عیب‌یابی Abyss Tunnel

## دستگاه‌های پشتیبانی‌شده
این صفحه برای Android، Windows، macOS، Linux و iOS راهنمای عمومی می‌دهد؛ نام منوها با نسخه برنامه فرق می‌کند. لینک‌های دانلود به صفحه رسمی پروژه یا فروشگاه رسمی می‌روند. به‌دلیل تفاوت معماری دستگاه و امضای بسته‌ها، از یک APK ثابت برای همه گوشی‌ها استفاده نکن.

## اتصال با لینک اشتراک
1. صفحه اشتراک شخصی را باز کن.
2. برنامه سازگار با VLESS را از صفحه رسمی پروژه نصب کن.
3. لینک اشتراک را کپی کن.
4. در برنامه، گزینه افزودن Subscription / Import from URL را انتخاب و لینک را وارد کن.
5. Update/Refresh را بزن تا پروفایل‌ها وارد شوند.
6. یک پروفایل را انتخاب و Connect را بزن. مجوز VPN را فقط در پنجره خود سیستم تأیید کن.

## اتصال مستقیم با یک پروفایل
در صفحه اشتراک روی یکی از کارت‌های پروفایل بزن. اگر برنامه روی دستگاه برای بازکردن لینک نصب باشد، باید درخواست واردکردن لینک را نشان دهد. در غیر این صورت از گزینه کپی لینک اشتراک استفاده کن.

## اگر اتصال برقرار نشد
1. در صفحه اشتراک «بررسی اتصال» را اجرا کن. این بررسی وضعیت سرویس و لینک را می‌سنجد، نه اینکه تونل را از دستگاه تو تا اینترنت آزمایش کند.
2. مطمئن شو سرویس منقضی نشده و حجم باقی مانده است.
3. برنامه را به‌روزرسانی کن و Subscription را Refresh کن.
4. چند پروفایل مختلف را امتحان کن. یک مسیر ممکن است روی یک اپراتور کار کند و روی دیگری نه.
5. زمان دستگاه را روی تنظیم خودکار قرار بده و اتصال HTTPS به دامنه را بررسی کن.
6. اگر مشکل ادامه داشت، نام اپراتور، نوع دستگاه، نام و نسخه برنامه، نام پروفایل و متن خطا را برای پشتیبانی بفرست. لینک کامل اشتراک و کلید API را عمومی نکن.

## دسته‌بندی اپراتورها و انتخاب مسیر
شش پروفایل فعلی از نظر انتقال متفاوت‌اند: WebSocket، HTTPUpgrade و چهار حالت XHTTP. این‌ها کانفیگ‌های واقعی متفاوت‌اند، اما در حال حاضر مسیر اختصاصیِ تأییدشده برای هر اپراتور به‌صورت خودکار ادعا نمی‌شود. ابتدا هر مسیر را روی همان سیم‌کارت و همان دستگاه تست کن؛ بعد از تست واقعی می‌توان ترتیب پیشنهادی هر اپراتور را تنظیم کرد. صرفاً کپی‌کردن یک لینک با برچسب «ایرانسل» یا «همراه اول» آن را به مسیر بهینه تبدیل نمی‌کند.

## درباره پینگ و سرعت
عدد پینگ واقعی باید از خود برنامه مشتری یا آزمایش از همان اپراتور و همان منطقه گرفته شود. اندازه‌گیری CPU/RAM پنل یا پاسخ HTTP از سرور جایگزین پینگ تونل نیست. تعداد بیشتر پروفایل‌ها به‌تنهایی سرعت یا پینگ بهتر را تضمین نمی‌کند.
